## Sobre a exportação original

O Claude Code permite exportar a transcrição da sessão (menu da sessão → *Export*), gerando um
`.zip` local. Antes de anexar esse arquivo ao repositório, revise o conteúdo: a transcrição
traz contexto do ambiente local (caminhos da máquina, e-mail da conta), e o `AGENTS.md`
proíbe versionar dados pessoais ou sensíveis. Se for publicá-la, remova esses dados e registre
aqui que o arquivo foi **editado** para anonimização.
