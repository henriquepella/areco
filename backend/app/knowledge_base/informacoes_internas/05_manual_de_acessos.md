# Solicitação de acesso a sistemas

**Documento fictício para avaliação de agente de IA.** Versão 1.0 — 05/02/2026.

1. Abra chamado no portal de TI com sistema, perfil necessário e justificativa.
2. A liderança valida a necessidade de negócio.
3. O proprietário do sistema aprova o perfil.
4. TI provisiona o acesso após as aprovações.
5. O solicitante recebe atualização pelo número do chamado.
6. A remoção de acesso de pessoas desligadas é tratada pelo fluxo de desligamento.

**Prazo de referência:** até 2 dias úteis após todas as aprovações. Não compartilhe credenciais entre pessoas.
